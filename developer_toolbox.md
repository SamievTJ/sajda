# 🛠️ Стартовый набор веб-разработчика: Инструменты и Программы

Привет! Это абсолютно правильный подход. Прежде чем бросаться в бой и писать код, очень важно подготовить удобное рабочее место на компьютере. Когда инструменты настроены правильно, процесс обучения и разработки становится в 10 раз приятнее и проще!

Ниже представлен полный список программ, расширений и инструментов, которые пригодятся тебе при работе со мной и для самостоятельного изучения веб-разработки.

---

## 💻 1. Основные программы (Обязательно к установке)

Помимо **Git**, который мы уже установили, тебе понадобятся две главные программы:

### 1. Редактор кода: **Visual Studio Code (VS Code)**
Это лучшая и самая популярная программа для написания кода в мире. Она полностью бесплатна и очень удобна.
* **Для чего нужен:** В нем мы будем открывать наши папки, писать HTML, CSS и JavaScript.
* **Где скачать:** [https://code.visualstudio.com/](https://code.visualstudio.com/) (нажми синюю кнопку **Download for Windows**).
* **Как устанавливать:** Скачай, запусти и нажимай "Далее" (настройки по умолчанию идеальны).

### 2. Среда выполнения: **Node.js**
Это специальная платформа, которая позволяет запускать код JavaScript прямо на твоем компьютере (а не только внутри браузера). Вместе с ней устанавливается **npm** — менеджер пакетов, с помощью которого мы сможем скачивать готовые библиотеки (например, для красивых графиков, иконок или анимаций).
* **Для чего нужен:** Для запуска серверов, установки библиотек и создания современных проектов (например, на React, Next.js или Vue).
* **Где скачать:** [https://nodejs.org/](https://nodejs.org/) (всегда выбирай версию с пометкой **LTS** — она самая стабильная).
* **Как устанавливать:** Стандартная установка, просто нажимай "Next".

## 🔌 2. Расширения для VS Code (Упрощают жизнь в 10 раз)

После того как ты установишь **Visual Studio Code**, внутри него можно установить мини-плагины (расширения). Чтобы их установить, открой VS Code, нажми на иконку квадратиков слева (плитки/расширения, или нажми `Ctrl + Shift + X`), введи название в поиск и нажми **Install**.

Вот список самых полезных расширений для новичка:

1. **Russian Language Pack for Visual Studio Code**
   * **Зачем:** Переводит весь интерфейс VS Code на русский язык. Новичку будет гораздо проще ориентироваться в настройках и меню.
2. **Live Server** (от автора *Ritwick Dey*)
   * **Зачем:** Позволяет запустить твой сайт локально в один клик. При этом, как только ты или я изменим код в файле, страница в браузере автоматически обновится сама! Не придется постоянно нажимать `F5`.
3. **Prettier - Code formatter**
   * **Зачем:** Автоматически выравнивает и форматирует код (делает красивые отступы, расставляет скобки). Твой код всегда будет выглядеть профессионально и аккуратно.
4. **Auto Rename Tag**
   * **Зачем:** Если ты меняешь открывающий HTML-тег (например, `<div>` на `<section>`), это расширение автоматически переименует и закрывающий тег `</div>` на `</section>`. Предотвращает 90% глупых ошибок у новичков.
5. **Material Icon Theme**
   * **Зачем:** Делает иконки файлов и папок в VS Code очень красивыми и понятными (у файлов HTML будет иконка HTML5, у папки Git — значок гита и т.д.).

## 🌐 3. Браузер и инструменты разработчика

Для работы подойдет любой современный браузер: **Google Chrome**, **Microsoft Edge** или **Яндекс.Браузер**.

> [!TIP]
> **Главный инструмент для изучения:** В любом браузере есть скрытый инструмент — **Панель разработчика** (DevTools).
> * Чтобы её открыть, нажми клавишу **F12** (или кликни правой кнопкой мыши в любом месте страницы и выбери **«Просмотреть код»** / **«Исследовать элемент»**).
> * Там ты увидишь вкладку **Console** (Консоль) — туда выводятся ошибки кода, и вкладку **Elements** (Элементы), где можно увидеть структуру сайта и менять стили "на лету" прямо в браузере! Это невероятно полезно для обучения.

## 📈 Что стоит начать изучать прямо сейчас?

Если ты хочешь постепенно разбираться сам, вот идеальный порядок изучения технологий для веб-разработки:

1. **HTML (Язык разметки):** Это «скелет» сайта. Он отвечает за то, где будут находиться текст, кнопки, картинки и формы. (Изучается за 1-2 вечера).
2. **CSS (Каскадные таблицы стилей):** Это «одежда» и макияж сайта. Он отвечает за цвета, шрифты, размеры, отступы, тени и красивое расположение элементов на экране. (Изучается постепенно, основам можно научиться за неделю).
3. **Git (Контроль версий):** То, что мы установили. Достаточно знать 3-4 базовые команды (как сохранить код и отправить его на GitHub). Я помогу тебе с этим на практике.
4. **JavaScript (Язык программирования):** Это «мозг» сайта. Он делает сайт живым: обрабатывает клики по кнопкам, открывает модальные окна, отправляет формы без перезагрузки страницы и делает анимации.
